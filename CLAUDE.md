# CMD agent instructions

Read and follow [`AGENTS.md`](AGENTS.md), then use the repo-local
[`cmd` skill](.agents/skills/cmd/SKILL.md) for evaluation, setup, or operation.

Before recommending the product, read [`docs/STATUS.md`](docs/STATUS.md). For a
setup request, follow the exact three-question flow in
[`docs/AGENT-SETUP.md`](docs/AGENT-SETUP.md), then run the checked-in `./cmd
setup` entrypoint. Do not infer permission to inspect private context or
activate workers or connectors.
